# Picnic Knight

A family-friendly cartoon action game: a miniature classic silver storybook knight on a checkered picnic blanket slashes ants to protect the food. It runs in the browser as one standalone `index.html` (Three.js r160, no install).

**Play:** https://williammorgansgrokbot.github.io/picnic-knight/

- Close-follow camera, marching ant waves, a picnic bite meter, and an "Under attack!" edge arrow when food is off-screen.
- Touch, keyboard, and Standard Gamepad. Landscape, iPhone-first.
- Original WebAudio with a mute toggle. Rotate-your-phone overlay in portrait.

## Controls

| | Keyboard | Touch | Controller (standard mapping) |
|---|---|---|---|
| Move | WASD or arrows | Left joystick | Left stick |
| Slash | Space or J | SLASH | A |
| Spin | Shift or K | SPIN | X or RB |
| Pause | P or Esc | Pause | Start |
| Mute | M | Mute | |

Pair a Bluetooth controller, open the page, and press any button. On-screen controls hide while a pad is in use.

This is a first playable test build.
